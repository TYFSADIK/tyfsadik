## Defence Hardware Program

Canada's Defence Drone Initiative, the Army's MINERVA challenges and DRDC field trials say in public
exactly what they want built. I read them as requirement specs and build against them at hobby scale,
with real hardware, simulations that run on open data, and results published only when they're real.
